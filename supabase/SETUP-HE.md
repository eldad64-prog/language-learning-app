# הקמת Supabase לאפליקציית לימוד השפות

## הפרדה ובטיחות
- יש ליצור פרויקט Supabase חדש בשם `Language Learning` בארגון נפרד אם אפשר.
- לבחור אזור Singapore / Southeast Asia.
- לא לשנות או למחוק את פרויקט Loan Management.
- להגדיר סיסמת DB ייחודית ולשמור אותה במנהל סיסמאות. אין להכניס אותה לקוד או לשלוח אותה בצ'אט.
- בהגדרות יצירת הפרויקט: להשאיר Data API פעיל; לכבות Automatically expose new tables; להפעיל RLS אוטומטי אם האפשרות זמינה.
- לאחר היצירה, להריץ את `supabase/schema.sql` ב-SQL Editor של הפרויקט החדש בלבד.

## מבנה נתונים
- `profiles`: פרופיל נפרד לכל חשבון משתמש.
- `learning_items`: מילים ומשפטים עם שפת מקור, שפת יעד, תעתיק, נושא ותרגום.
- `learning_progress`: התקדמות אישית לפי משתמש ופריט.
- `test_attempts`: תוצאות מבחנים והיסטוריית תשובות.
- `pronunciation_recordings`: הקלטות אישיות ומטא-נתונים.
- Storage bucket פרטי: `pronunciation-recordings`.

## אבטחה
כל הטבלאות מפעילות Row Level Security. משתמש מחובר יכול לראות ולשנות רק את הפרופיל, ההתקדמות, המבחנים וההקלטות שלו. תוכן לימודי שפורסם משותף לקריאה; תוכן אישי ניתן לעריכה רק ליוצר שלו. הקלטות נשמרות ב-bucket פרטי, בתיקייה ששמה מזהה המשתמש.

## חיבור האפליקציה
אחרי יצירת הפרויקט והרצת הסכימה, יש להגדיר באפליקציה את Project URL ואת publishable/anon key של הפרויקט החדש. לעולם אין להכניס service_role key או DB password לקוד צד-לקוח.

## מצב נוכחי
הקובץ הזה והסכימה אינם מחוברים עדיין לאתר החי. קובצי השורש של GitHub Pages לא שונו, ולכן האפליקציה הקיימת ממשיכה לפעול כרגיל. לאחר יצירת הפרויקט, יש לבצע חיבור מדורג ולבדוק סנכרון בין שני מכשירים, פרטיות משתמשים, שמירת הקלטות ועבודה לא מקוונת.
