# מסע ללימוד שפות

אפליקציית PWA ראשונית בעברית ללימוד תאית ואנגלית.

## בגרסה הראשונית
- בחירת פרופיל: אלדד או ליאורה
- בחירת תאית או אנגלית וקטגוריית לימוד
- משפטים לדוגמה, תעתיק לטיני לתאית ותרגום לעברית
- הקראה באמצעות מנוע הדיבור במכשיר, אם זמין
- מועדפים, סימון משפטים שנלמדו והתקדמות מקומית
- Service Worker לשימוש לא מקוון לאחר טעינה ראשונה

## הפעלת GitHub Pages
1. פתחו Settings במאגר.
2. בחרו Pages.
3. תחת Build and deployment בחרו Deploy from a branch.
4. בחרו main ואת /(root), ואז Save.
5. לאחר הפרסום פתחו את כתובת האתר בטלפון כשהוא מחובר לאינטרנט.

## חשוב
זו גרסת אב-טיפוס עם מספר מצומצם של משפטים לדוגמה, לא מאגר של 1,000 משפטים בכל שפה. התקדמות ומועדפים נשמרים בדפדפן ובמכשיר המקומי בלבד; אין סנכרון בין מכשירים. איכות ההקראה הלא מקוונת תלויה בקולות המותקנים במכשיר.
